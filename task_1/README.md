# Loading Skeleton States for a Data List

This project demonstrates a skeleton loading state for a service card list.

## Features
- Four service cards
- CSS shimmer skeleton animation
- Simulated asynchronous loading using JavaScript setTimeout()
- Skeleton content is replaced with real content after 1.5 seconds

## Technologies
- HTML5
- CSS3
- JavaScript

## Testing
The page was tested using Chrome DevTools, including network throttling.
